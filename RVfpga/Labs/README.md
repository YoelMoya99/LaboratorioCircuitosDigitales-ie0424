# Estructura general de la carpeta

En la carpeta `Consola` se encuentra el proyecto de platformIO que contiene el archivo final del còdigo funcional. Este còdigo presenta todas las partes mostradas en la demostraciòn del demo. Mas la documentaciòn del mismo a nivel de comentarios.

En la carpeta `temp` se incluyen diferentes versiones del proceso de desarrollo del proyecto, debido a que se tuvo problemas de conexiòn a internet y acceso al repositorio por parte de los integrantes del grupo. Estas versiones se encuentran enumeradas segun su antiguedad, siendo la "1" la mas antigua.
